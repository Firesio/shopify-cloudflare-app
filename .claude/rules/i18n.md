# Words and languages

ONE catalogue for the pages and the mail (`@firesio/app/i18n`, `node_modules/@firesio/app/src/i18n/README.md`): `app/i18n/locales/<language>/<namespace>.json`, i18next-style nested keys.

- **The app's languages ARE its folders** (`en`, `es` in the template): nothing else lists them. A folder is the canonical tag as `Intl` writes it (`zh-CN`). The fallback is `en`.
  A new language is a new folder with every key; `app/i18n/catalogue.test.ts` (`assertCatalogueComplete`) fails until every key, every `{{placeholder}}` and every plural form is there.
  The package's own pages ship English, Spanish and German words (the `firesio` namespace); an app swaps a word of theirs in its own `locales/<language>/firesio.json` (a team-up app says "Staff"
  for "Team") and adds a language by adding the folder.
- **Every user-visible string of the app's own is a key**: the embedded pages, the mail, the public pages that are not placeholders. `t("home.store", { shop })`, placeholders `{{x}}`
  (`{{x, number|date|money|list}}` for formats), a count picks the plural form (`key_one`, `key_other`; `ar` needs six, `ja` one). Never ICU `{x, plural, ...}`. A missing key shows
  as the key itself and is reported: a gap is visible, never blank.
- **A component never reads the catalogue.** A loader builds a plain-string label object (`app/i18n/labels.ts`: `navLabelsOf(t)`, `homeLabelsOf(t, values)`) and the component takes it as props,
  so a test hands it any words. The package's pages do the same (`membersLabelsOf(t, ...)`).
- **The language of a request** is `?locale=`, the `firesio_locale` cookie, the language remembered on the member, then `Accept-Language`, negotiated by CLDR and script among the folders
  (`localeIn(I18N)(request)`, or `localeIn(services.i18n)(request, member.locale)` in a loader). In the embedded admin it comes from Shopify's `locale` parameter: **never add a language switcher
  there**. `zh-TW` is never read as `zh-CN`.
- **No hand-formatted dates, money or numbers**: `t.format` (`date`, `money`, `number`, `list`; money is integer minor units and a currency, `@firesio/app/money`). The time zone is the
  viewer's, never the machine's.
- **Shopify-specific words** (a Polaris component's own text, an App Bridge string) are Shopify's; do not translate them by hand.
